# Albion Tools

アルビオン・オンライン用の自分用の計算機。依存なしの静的 HTML だけで、ビルドは要らない。

**https://minojun.github.io/albion-tools/**

## 道具

### [闇市クラフト採算表](bm-calc/) — `bm-calc/`

カーレオンで素材を買って現地でクラフトし、闇市に並べた時の採算表。
作業台に出ている **「栄養100あたり◯シルバー」** を入れると、145品ぶんの
使用料・素材の実費・損益ゼロで並べられる出品額・余裕%・1個の損益・名声/個・**銀/名声**・銀/フォーカス が並ぶ。

- 価格は [Albion Online Data Project](https://www.albion-online-data.com/) の公開 API からページが直接取得（東・西・ヨーロッパを切替）。取得できない時は内蔵スナップショットで動き、素材の値段は手入力で上書きできる
- レシピ・アイテム価値・フォーカス消費・日本語名は公式ゲームデータ [ao-data/ao-bin-dumps](https://github.com/ao-data/ao-bin-dumps) から生成
- 行をクリックすると1個ぶんの計算が1行ずつ開く（ゲーム内の表示と突き合わせて検算するため）

## 計算の前提

| | |
|---|---|
| 使用料 | アイテム価値 × 0.1125 × 栄養100あたりの単価 ÷ 100 |
| アイテム価値 | 素材の価値の合計。加工済み素材は T4=16 で1ティアごとに倍、エンチャント1段でも倍 |
| 製造名声 | アイテム価値 × 1.40625（プレミアムで ×1.5） |
| 手取り | 出品 ×0.935（設定手数料2.5%＋売却税4%）／即売り ×0.96。非プレミアムは売却税8% |
| 素材の戻り率 | 基礎15.2% ／ ボーナス都市36.7% ／ フォーカス43.5% ／ 両方53.9%（デイリー生産ボーナスの日はボーナス都市がさらに1.1倍） |
